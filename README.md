## 先搞懂免費版能幹嘛，再決定要不要付費

剛註冊的 PikPak 帳號，官方給你 **6GB 的基礎儲存空間**。6GB 聽起來不多，但用來測試功能是夠的——你可以試試離線下載的速度、試試把影片存進去再線上播放，感受一下這個工作流程是不是你需要的東西。

不過免費版有個明顯限制：**下載到本地的速度會被限制在約 400KB/s**。這意味著你要把一個 1GB 的檔案拖到電腦上，大概需要等40分鐘。雲端存取、線上播放還可以，但本地下載這條腿確實短了一截。

開通 Premium 之後，情況就完全不同了：

- 儲存空間從 6GB **直接跳到 10TB**（大約能放 8000 部 HD 畫質影片）
- 伺服器端離線下載速度最高 **8MB/s（區域會員）或 20MB/s（全球會員）**
- 支援 **4K 原畫質線上播放**，就像在用私人 Netflix
- 可同時執行多個雲端下載任務，不用排隊
- 支援 **WebDAV 協議**，可接 Infuse、Nplayer 等播放器
- 支援 **ZIP/RAR 雲端解壓縮**，不用下完再解
- **Telegram Bot 功能**：直接把連結丟給 Bot，檔案自動存進你的雲盤

如果你只是偶爾好奇試試，免費版夠用。但如果你是重度使用者，免費版那 400KB/s 很快就會讓你抓狂。

## 會員到期後，我的檔案會怎樣？

這個問題很多人沒想清楚就買了，這裡直接說透。

會員到期後，你的帳號回到免費用戶狀態（6GB 配額）。如果你在 Premium 期間存了超過 6GB 的檔案：

- **前7天**：可以存取和管理現有檔案，但無法上傳新檔案或新增下載任務
- **7天後**：線上播放功能關閉，本地下載速度降至 100KB/s
- **超額狀態持續超過4個月**：系統開始以電子郵件提醒你，進入2個月寬限期
- **6個月後仍未處理**：系統按修改時間由舊到新，自動刪除超出配額的檔案，**刪除後無法復原**

所以如果你打算存大量檔案，要麼維持會員訂閱，要麼在到期前把重要的東西下載到本地備份。
